# Institute of Fine Arts - Management System

A full-stack web application built with **C# and ASP.NET Core MVC**. This system is designed to manage an art institute, including artists, exhibitions, competitions, and student submissions.

## 🚀 Features
- **Role-based Authentication:** Secure login for Admins and Users.
- **Artist & Exhibition Management:** Complete CRUD operations for artists and exhibitions.
- **Competitions & Submissions:** Manage art competitions and track user submissions.
- **File Uploads:** Users can upload their artwork images seamlessly.
- **Responsive Admin Dashboard:** A clean and modern dashboard for complete control.
- **SQL Server Integration:** Uses Entity Framework Core for database management.

## 💻 Technologies Used
- **Framework:** C#, ASP.NET Core MVC
- **Database:** SQL Server (Entity Framework Core)
- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
- **Architecture:** MVC (Model-View-Controller)

## ⚙️ How to Run This Project Locally
1. Open the solution file (`.sln`) in **Visual Studio**.
2. Open `appsettings.json` and update the connection string to match your local SQL Server.
3. Open the **Package Manager Console** and run `Update-Database` to create the database.
4. Press `F5` to run the application.
